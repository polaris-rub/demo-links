Durchschnittliche Quizpunktzahl je Kurs

Eine Analyse aus vier Knoten, die zeigt, wie sich mit dem visuellen Pipeline-Editor aus eingehenden xAPI-Statements eine fertige Auswertung je Kurs bauen lässt: vom Laden der Rohdaten über das Filtern bis zur Berechnung und Speicherung des Ergebnisses.

Bevor Sie starten

Prüfen Sie in den Einstellungen dieser Analyse unter Konfiguration → Verfügbare Verben, dass die hier benötigten Verben (hier: answered) für den verwendeten Provider ausgewählt sind. Fehlt diese Freischaltung, liefert der xAPI Source keine Statements – ohne Fehlermeldung.

1

xAPI Source

Lädt nur die Quiz-Antworten aus dem LRS.

JSON-Filter

{ "verb.id": "https://xapi.elearn.rwth-aachen.de/definitions/lms/verbs/answered" }

Max. Statements

1000

Der Standardwert (10) ist nur für eine schnelle Vorschau gedacht – für eine echte Auswertung über den gesamten Datenbestand hier eine ausreichend hohe Zahl eintragen, sonst rechnet Schritt 3 nur mit einem kleinen, zufälligen Ausschnitt statt allen Daten.

2

Filter

Reduziert auf überwiegend richtig beantwortete Versuche (Score ≥ 50 %).

Bedingung

result.score.scaled ≥ 0.5
3

Python Code

Berechnet je Kurs den Mittelwert des skalierten Scores.

Code

from collections import defaultdict

def kurs_name(stmt):
    grouping = stmt["context"].get("contextActivities", {}).get("grouping", [])
    for eintrag in grouping:
        definition = eintrag.get("definition", {})
        if definition.get("type", "").endswith("/activities/course"):
            name = definition.get("name", {})
            return name.get("de") or name.get("en") or eintrag.get("id", "Unbekannt")
    return "Unbekannt"

summe  = defaultdict(float)
anzahl = defaultdict(int)
for stmt in in1_data:                      # Eingang in1 aus dem Filter
    kurs  = kurs_name(stmt)
    score = stmt["result"]["score"]["scaled"]
    summe[kurs]  += score
    anzahl[kurs] += 1

out1_data = [
    {"Kurs": k, "Schnitt": round(summe[k] / anzahl[k], 2)}
    for k in summe
]

Die vier Knoten müssen zusätzlich durch Linien miteinander verbunden werden (jeweils vom Ausgang zum Eingang, in der Reihenfolge oben) – erst dadurch entsteht ein durchgängiger Datenfluss. Ohne diese Verbindungen läuft die Pipeline scheinbar erfolgreich durch (grüner Status, kein Fehler), verarbeitet dabei aber nichts und speichert kein Ergebnis.
