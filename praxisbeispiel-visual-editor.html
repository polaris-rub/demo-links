Durchschnittliche Quizpunktzahl je Kurs

Eine Analyse aus vier Knoten, die zeigt, wie sich mit dem visuellen Pipeline-Editor aus eingehenden xAPI-Statements eine fertige Auswertung je Kurs bauen lässt: vom Laden der Rohdaten über das Filtern bis zur Berechnung und Speicherung des Ergebnisses.

Bevor Sie starten

Prüfen Sie in den Einstellungen dieser Analyse unter Konfiguration → Verfügbare Verben, dass die hier benötigten Verben (hier: answered) für den verwendeten Provider ausgewählt sind. Fehlt diese Freischaltung, liefert der Statement-Loader keine Statements – ohne Fehlermeldung.

1

Statement-Loader

Lädt nur die Quiz-Antworten aus dem LRS.

JSON-Filter

{ "verb.id": "https://xapi.elearn.rwth-aachen.de/definitions/lms/verbs/answered" }
2

Statement-Filter

Reduziert auf erfolgreiche Versuche.

Bedingung

result.success == true
3

Python-Code-Snippet

Berechnet je Kurs den Mittelwert des skalierten Scores.

Code

from collections import defaultdict

summe  = defaultdict(float)
anzahl = defaultdict(int)
for stmt in in1_data:                      # Eingang in1 aus dem Filter
    kurs  = stmt["context"]["platform"]
    score = stmt["result"]["score"]["scaled"]
    summe[kurs]  += score
    anzahl[kurs] += 1

out1_data = [
    {"Kurs": k, "Schnitt": round(summe[k] / anzahl[k], 2)}
    for k in summe
]
